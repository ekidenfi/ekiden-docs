## Production

Use the production environment for live integrations with Ekiden.

- **REST**: [https://api.ekiden.fi/api/v1](https://api.ekiden.fi/api/v1)
- **WebSocket public**: wss://api.ekiden.fi/ws/public
- **WebSocket private**: wss://api.ekiden.fi/ws/private

See [Client Initialization](/api-reference/integration/initialization) for setup and [API Authentication](/api-reference/integration/onboarding-auth) for credentials.

## Staging

The staging environment is reserved for authorized development and integration testing. Request access from the Ekiden team before using it.

- **REST**: [https://api.canton.ekiden.fi/api/v1](https://api.canton.ekiden.fi/api/v1)
- **WebSocket public**: wss://api.canton.ekiden.fi/ws/public
- **WebSocket private**: wss://api.canton.ekiden.fi/ws/private
